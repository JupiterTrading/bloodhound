# BLOODHOUND — AI Instructions

## Design Context

### Users
Crypto traders, on-chain researchers, and intelligence analysts who track Solana wallets and transactions. They arrive with specific intent — investigating a wallet, tracing fund flows, or monitoring trading patterns. They expect professional-grade tooling that surfaces complex data quickly and clearly. Context is urgent; they're often making time-sensitive decisions.

### Brand Personality
**Intuitive · Intelligent · Beautiful**

The interface should feel like a precision instrument — every element purposeful, every interaction considered. The tool exudes quiet confidence. It doesn't shout; it delivers. Think: Bloomberg terminal meets modern design sensibility.

### Aesthetic Direction
- **Visual tone:** Dark, high-contrast, data-forward. Calm but alive.
- **Theme:** Dark mode primary (near-black `#0d0a0a` base)
- **Accent:** Blood red `#b30000` — used sparingly for CTAs, alerts, active states
- **Typography:** JetBrains Mono for all data/addresses, Inter/NHGrotesk for UI
- **Motion:** Constant subtle life — pulsing status indicators, streaming feeds, smooth micro-interactions. The site should feel like a live terminal, never static.
- **Texture:** Subtle scanlines on background, grid overlay on hero sections
- **References:** Arkham Intelligence (functionality), Nansen (polish), Bloomberg terminal (data density)
- **Anti-references:** No cluttered dashboards, no overwhelming UI, no generic crypto aesthetics, no static/lifeless pages. Every screen must feel alive and cutting-edge.

### Design Principles

1. **Data is the hero** — Information hierarchy matters. The most important data should be immediately visible. Use typography weight, spacing, and color to guide the eye.

2. **Alive, not animated** — Subtle constant motion (pulsing badges, streaming feeds, blinking cursors) creates a sense of real-time intelligence. Avoid gratuitous animation that distracts.

3. **Precision over decoration** — Every element earns its place. No ornamental flourishes. Clean lines, tight spacing, purposeful use of color.

4. **Confidence through restraint** — Three-color palette (black/white/red). Let the data speak. The UI should feel like infrastructure, not a marketing site.

5. **Intelligent defaults, powerful depth** — Surface the most useful view first. Power users can dig deeper. Never overwhelm on first load.
